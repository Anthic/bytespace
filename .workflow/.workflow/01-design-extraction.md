# Design extraction (per section)
Checklist — record results in `.workflow/notes.md`:
- [ ] Node id of the section frame for each breakpoint (mobile / tablet / desktop).
- [ ] Reference screenshot fetched from Figma MCP for each breakpoint. Save as `.workflow/shots/ref/<section>-<width>.png`.
- [ ] Layout: auto-layout direction, gap, padding, alignment, fixed/hug/fill.
- [ ] Typography per text layer: font, weight, size, line-height, letter-spacing, color, case.
- [ ] Colors/gradients/shadows/borders/radii mapped to tokens.
- [ ] Assets exported to `public/`.
- [ ] Interactions/prototype hints noted (hover, scroll, transitions).
- [ ] Animation opportunities listed (entrance, lines, parallax, hover).
